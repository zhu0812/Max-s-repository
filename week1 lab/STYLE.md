# Our coding style 
- Pick variable names that make sense at a glance; avoid random single-letter names.
- Don’t cram too much code onto one line — split it up if it gets long.
- Add comments only for tricky parts. Don’t repeat what the code already shows.
- Stick to the same indent: four spaces for Python, two for JavaScript.
- Leave a blank line between separate chunks of code so it’s easier to follow.
- Test your code before pushing it to the repo.
- Use simple, lowercase names for files.
